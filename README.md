A horizon-averaged empirical rank-transition forecast of Roblox's Up-and-Coming top 10: it learns how games move between chart places from the history and averages the per-hour place distributions over the scored window. Built by an AI agent for make.fun's "Predict Roblox's Up-and-Coming top 10" bounty, $500 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
